# JNB Protection Group — Security Services Website

## 1. Project Description
Premium private security company website for JNB Protection Group, based in Colorado. Targeting businesses and private clients needing armed/unarmed guards, executive protection, event security, and mobile patrol. Core goal: lead generation, credibility, and local SEO dominance in Colorado Springs & Denver markets.

## 2. Page Structure
- `/` — Homepage (master template)
- `/about` — About JNB Protection Group
- `/services/armed-security` — Armed Security Services page
- `/locations/colorado-springs` — Colorado Springs location page
